## A. UI 規格書

### A1. 設計規則

- 邏輯尺寸固定 `1920×1080`，目前預設視窗 `1600×900`，比例 16:9；保持既有 Godot `CanvasLayer` 控制與九宮格面板。正常畫面無 Debug 網格。
- 視覺方向：深鋼灰工業機庫 + 黃色壁壘重裝型主角 + 電藍導引線與金色聚焦；背景可細緻柔化，人物畫素邊界保持 Nearest。
- 先採用已授權專案內 1103 機甲角色資產與新繪原創場景／圖示；高解析原創插畫屬後續替換層，**不得用貼圖中的假按鈕代替可點選控制**。
- 主選單資訊遵循真實性：`信用點` 使用 `progress.credits`，`歷次成績` 使用 `cached_scores`；右上顯示「本機指揮官 / 本機檔案」，不模擬線上玩家等級、郵件或通知。
- 底部活動採現有「工業廢墟 / 主線行動」說明，更新欄顯示實際本機版本里程碑；不得暗示尚未發布的活動或版本已上線。

### A4. 動畫規格

- 畫面進入：全景先顯示，左側選單 0.30s 淡入滑入，各列錯開 35ms；不阻止互動。
- Hover／鍵盤 Focus：125–170ms，藍框轉金、左側光條提亮與 2% 區域性位移；滑鼠離開與失去焦點復原。
- 點選：不改原 callback 或測試 action，觸發原 screen 跳轉，沿用現有 UI 點選音效。
- 背景：只用低幅度透明光束與機甲呼吸（不改玩家動畫資產）；不使用大面積常駐閃白。
- 低畫面負載：效果用 `Tween` 和 `Control`；不得建立遊戲物理節點或更改 `Engine.time_scale`。
