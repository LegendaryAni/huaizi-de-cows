版本：v3.0 / 2026-10-19 / Godot 4.7.2
沿用 GOAL：wc_goal_MXBwdHzPm7MiFYqS

本文件是**待實作的新版本規格**，不是完成報告。使用者的視覺目標為先前提供的機甲機庫首頁：大型機甲與場景主導視覺、左側遊戲入口、右上簡潔玩家資訊、左右下方各一塊內容模組。避免重新製作目前「小機甲展示台＋底部整條報表＋小型功能清單」的格局。

### 4. 美術語言

- 背景：鋼灰、遠景冷藍、局部暖黃作業燈；有真正透視的維修機庫，非泛用發光網格。
- 主機甲：以壁壘 1103 為主角。右側機庫的胸甲／頭部為視覺錨點，姿態有重量感。
- UI：圖示大、字少、有區分主次的按鈕組；不製造過量細框資料卡。
- 左下任務 Banner：關卡插圖／縮圖＋真實模式文字；右下僅放實際可查的本機版本訊息。
- UI 完全是可操作的 Godot Control，不能把按鈕、文字直接烘焙進背景。
- 專案目前 SF-13 使用統一像素風及 Nearest，美術參考卻傾向電影式高解析機甲。第一版先做隔離預覽候選，正式修改像素風驗收基準前需經使用者確認。

## C. 動畫完整規格

### 1. 首次進場

| 動畫 | 時長 | 內容 | Godot |
|---|---|---|---|
| 機庫亮相 | 0.60 秒 | 深色場景略提亮，背景由 96% 到 100% | AnimationPlayer |
| 遊戲 Logo | 0.42 秒 | x -24px → 0，透明度 0→1 | AnimationPlayer |
| 選單顯示 | 每列 0.22 秒，延遲 0.045 秒 | 主操作先出現，其餘依次淡入 | AnimationPlayer/Tween |
| 主機甲亮相 | 0.65 秒 | 機甲輪廓逐漸明亮，胸燈最後亮起 | Material/Shader |
| 任務與版本卡 | 0.35 秒 | 透明度及 y +10px → 0 | Tween |

重要：進場不阻斷按鈕輸入，主要出擊按鈕在 0.5 秒內應可操作。

### 2. 常駐機庫動畫

| 動畫 | 週期 | 幅度 | 注意 |
|---|---|---|---|
| 機甲胸腔呼吸 | 2.8–3.6 秒 | Torso 上下 2–5px | 需分層機甲 |
| 手臂機械微動 | 5–8 秒 | 角度約 0.6–1.5 度 | 不可整台 PNG 無規則搖晃 |
| 偶發頭部掃描 | 7–11 秒 | 轉動約 2 度後回正 | 使用正確關節 pivot |
| 眼燈／胸燈呼吸 | 4–6 秒 | 明亮度 80–110% | 限定局部遮罩，不全畫面閃白 |
| 機庫吊架移動 | 9–14 秒 | 水平 25–55px | 必須沿軌道，動作間有停頓 |
| 作業燈明暗 | 5–10 秒 | 輕微明暗交替 | 不得高頻閃爍 |
| 環境霧與灰塵 | 持續 | 緩慢漂移，上限約 35 顆 | 不遮蔽 Logo／按鈕 |
| 鼠標微視差 | 即時 | 背景 ±3px、近景 ±9px | **不**移動 UI Hitbox |

目前 1103 角色原圖只有 96×96 像素。**只有完整分層機甲素材完成後，才可宣告胸腔／手臂／頭部的真正關節待機動畫完成。** 在此之前可先做好機庫、局部燈光、UI 與轉場；使用單張 PNG 漂浮不算完成真正機甲動畫。

### 3. UI 互動與場景切換

- Hover：0.12–0.16 秒，選取條與圖示亮起，裝飾箭頭輕移不超過 4px；不要直接改 Button Rect。
- Keyboard Focus：跟 Hover 等級一致，確保鍵盤方向／Tab 和 ui_accept 能操作。
- Click：0.08–0.10 秒，裝飾背景短暫壓下到 98.5% 後回彈；真實 Button Hitbox 不移動。
- 確認出擊：0.3–0.45 秒，機庫提示燈轉換、畫面淡出後進入原出擊整備。
- 其他頁面：切出 0.18–0.26 秒，返回時不得每次重播完整開場。
- 離開畫面：全部 Tween kill、AnimationPlayer stop、粒子停用，避免透明遮罩攔截點擊。
- 音效：沿用現有 SfxBus 的 UI 確認、Hover／點擊聲及玩家音量偏好。
- 減少動態選項：可關閉視差、吊架、粒子、機甲關節待機，保留必要按鈕 Focus。

### 4. 動畫效能與安全

AnimationPlayer 用於固定入場與循環；Tween 用於短互動；GPUParticles2D 用於受控環境粉塵。主選單動畫不能變動 Engine.time_scale、敵人或武器數值。關閉選單後不得有仍存活的 Tween callback 改寫新畫面。目標 60FPS 只是驗收目標，需實測幀時間，不能先宣稱達標。

4. 七個現有 action 保留；無虛構存檔、等級、在線訊息。
5. 動畫前後同樣的 HP、傷害、冷卻、信用點與保存邏輯不變。
6. SF-16 原成長平衡與 SF-17 審查若未通過，不能因新版首頁完成便宣稱整個 v0.2 合格。

## F. 本文件交付邊界

此版先定義新骨架、動畫要求、素材接口、Godot 工作拆分及驗收流程。**不是已替換遊戲首頁，也不是已生成高解析機甲素材。** 現行 96px 立繪與原有 UI 程式仍保留。正式大型機甲＋分層關節動畫，需要另製美術資產並在隔離預覽驗收後才接入預設主選單。
