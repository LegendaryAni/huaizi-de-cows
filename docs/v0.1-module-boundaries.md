# v0.1 模組邊界說明

本檔案記錄當前 v0.1 程式碼職責分工，用來複核 `AC-RUN-04`。它不定義新的玩法、數值或驗收標準；玩法數值仍以 `spec/遊戲機制.md` 為準，視覺要求仍以 `spec/視覺規格.md` 為準。

## 當前指令碼職責

| 檔案 | 當前職責 | 不負責 |
| --- | --- | --- |
| `scripts/GameConfig.gd` | 集中儲存地圖、玩家、貓、敵人、經驗、升級、波次、音效路徑等事實數值。 | 不執行執行時邏輯，不直接改節點狀態。 |
| `scripts/DirectionUtil.gd` | 按移動方向選擇 8 向動畫。 | 不決定角色或彈體移動。 |
| `scripts/Player.gd` | 處理花子移動、輸入讀取、邊界夾取、受擊無敵和相機跟隨。 | 不處理刷怪、攻擊、經驗、升級或結算。 |
| `scripts/Enemy.gd` | 處理單個敵人的移動、遠端牛吐奶請求、受擊和死亡判定。 | 不生成奶滴節點，不決定全域性刷怪節奏。 |
| `scripts/CatProjectile.gd` | 處理單個貓彈的飛行、壽命、方向動畫和命中記錄。 | 不選擇目標，不結算傷害。 |
| `scripts/MilkDrop.gd` | 處理單個奶滴的飛行、壽命和所屬遠端牛計數。 | 不處理玩家扣血。 |
| `scripts/XpOrb.gd` | 處理單個經驗球的吸附、飛向花子和收集判定。 | 不增加全域性經驗值，不觸發升級。 |
| `scripts/GameUI.gd` | 構建和重新整理 HUD、升級彈窗、暫停面板、勝負結算面板。 | 不決定玩法狀態和數值變化。 |
| `scripts/SfxBus.gd` | 載入、校驗、播放和統計音效事件。 | 不決定什麼時候觸發音效。 |
| `scripts/ValidationTools.gd` | 解析驗證引數、寫 JSON 報告、儲存截圖。 | 不承載核心遊戲邏輯。 |
| `scripts/Main.gd` | 編排一局遊戲：建立節點、物件池、刷怪、武器發射、碰撞結算、經驗升級、勝負、報告和驗證入口。 | 不儲存事實數值，不繪製 UI 結構，不實現單個實體的內部運動。 |

## `Main.gd` 的邊界

`Main.gd` 目前仍是 v0.1 的主編排指令碼，承擔較多流程串聯職責。它的合理邊界是：

- 讀取 `GameConfig.gd` 的事實數值。
- 呼叫實體指令碼的公開方法，例如 `Player.step_player()`、`Enemy.step_enemy()`、`CatProjectile.step_projectile()`、`XpOrb.step_xp()`。
- 維護物件池和全域性列表，避免執行中頻繁建立和銷燬核心戰鬥節點。
- 處理跨物件關係，例如貓彈命中敵人、奶滴命中花子、敵人死亡掉經驗。
- 觸發 UI 和音效，不在自身內部繪製正式 UI 資產。
- 提供預設關閉的驗證入口，生成報告和截圖證據。

後續如果繼續擴充套件 v0.2，優先把以下邏輯從 `Main.gd` 拆出去：

- 刷怪和波次推進可以拆成 `WaveDirector.gd`。
- 武器發射和目標選擇可以拆成 `WeaponDirector.gd`。
- 碰撞和傷害結算可以拆成 `CombatResolver.gd`。
- 驗證入口和報告取樣可以拆成 `ValidationProbeRunner.gd`。

## 當前複核結論

v0.1 已經把單體實體、UI、音效、數值、方向動畫和驗證工具拆到獨立指令碼；`Main.gd` 仍保留主編排職責。當前範圍內這可以接受，但後續版本不應繼續把新系統都塞進 `Main.gd`。
