# 《傳奇倖存者》電影式主選單 v3 隔離驗證案例

日期：2026-10-19。依 SF-01、SF-12、SF-13、SF-14、SF-15、SF-17 及 `docs/20261019_LegendarySurvivor_MainMenu_CinematicAnimation_Spec_v3.md` 制定。此為測試設計，不是通過結果。

- T-V3-01 Godot 編輯器載入與腳本解析：不得存在 parse error 或缺圖。
- T-V3-02 兩種 GPU 尺寸 1600×900 / 1920×1080：入場與穩定後的截圖；檢查可見 UI 控制項實際邊界不超出 1920×1080 設計視口。
- T-V3-03 確認七個 `scifi_action`（出擊、改裝、成績、設定、教學、來源、離開）皆有真實按鈕且互不重疊；主按鈕至少 88px 高。
- T-V3-04 分層主視覺：`HangarFar/Mid`、`HeroRig`、`LightRays`、`ForegroundRails` 各為獨立節點，不能用單張烘焙 UI 圖取代互動。
- T-V3-05 動畫：至少連續擷取主畫面進場（約 0–0.1s）、完成（0.8s）與 hover，需可從畫面確認不同；`AnimationPlayer` 的循環不依賴暫停戰鬥的時鐘。
- T-V3-06 按鈕：點擊設定並返回主選單、再進出教學、成績、改裝、來源及配裝頁；轉場後不得持續遮住點擊。
- T-V3-07 資料：`progress.credits`、歷次成績與存檔錯誤仍正確顯示；不得出現假的玩家等級、通知、郵件與線上活動。
- T-V3-08 現行主選單保持正式預設；只有 `--menu-v3-preview` 或 `--scifi-test=menu-v3` 啟用 v3。保留還原點。
- T-V3-09 完整遊戲 smoke、固定重播／基礎經濟，新增視覺不修改任何戰鬥或存檔數值。
- T-V3-10 獨立視覺／程式審查由不同於實作者的 reviewer 作出，沒有證據不得宣稱 SF-17 通過。
- T-V3-11 高解析分層機甲及手臂／頭部關節動畫屬獨立資產驗收，單張 96px Sprite 放大不能充當完成。
