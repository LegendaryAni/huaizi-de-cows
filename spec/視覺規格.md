# 視覺規格：傳奇倖存者

> **版本說明：** 本文件記錄《傳奇倖存者》**v0.1 早期原型**的規格／驗收歷史，包含當時不同的角色、武器、美術及波次機制，**不代表目前 v0.2 科幻機甲版本的玩法**。現行遊戲以 `spec/20261017_LegendarySurvivor_Scifi_v0.2.md` 與 SF-01～SF-17 的對應條款為準；原始歷史內容保留供版本追溯，AI 不得以本文件覆寫現行遊戲。

## 檔案職責

本檔案描述《傳奇倖存者》的執行時視覺表現，包括畫面風格、方向動畫、HUD、升級彈窗、結算面板、VFX、地圖視覺邊界、正式截圖限制和視覺證據要求。

本檔案不定義玩法數值、傷害公式、升級效果、波次節奏或勝負規則；這些內容以 `spec/遊戲機制.md` 為準。本檔案不定義素材目錄邊界；素材接入以 `assets/README.md` 及其子檔案為準。本檔案不定義詳細測試步驟；測試步驟由 `test-author` 根據驗收標準輸出到 `docs/` 目錄。

## 總體視覺目標

遊戲整體是手繪描邊、暗色高對比的漫畫街機風，不做畫素化處理。正式執行畫面應讓不看檔案的驗收者在短時間內看懂：花子在地圖裡移動，自動放貓攻擊一波波奶牛。

執行時視覺必須優先使用正式美術、動畫、執行時 UI 資產、粒子、短暫反饋和音畫結合來表達狀態。正常遊玩入口和正式視覺驗收截圖不顯示開發除錯標記。

## 解析度、鏡頭和地圖視覺

- 設計解析度為 1920x1080。
- 素材按原始畫素 1:1 顯示，Camera2D zoom 預設保持 1；如實際觀感需要，可在 0.8 到 1.2 之間微調。
- 主地圖 `full_outdoor_map_painted_4096x2305.png` 一屏約看到整圖四分之一，不能一次性顯示整張地圖。
- 地圖邊界必須透過圍欄、樹牆、石牆、水面、暗草邊、碎石帶或地形變化表達。正常畫面不能用矩形描邊、透明色塊、座標框或開發者邊界線表達可走範圍。
- 環境裝飾由 Godot 在底圖上疊加：圍欄、樹牆、石牆沿 `full_outdoor_map_manifest.json` 的視覺邊界佈置，水面 2 到 3 處，草叢、石頭、土堆在開闊區零散分佈。刷怪區和玩家出生點附近保持空曠可讀。

## 方向動畫

角色、貓彈、奶滴和牛的執行時方向表現必須跟隨當前移動或飛行方向。

方向分為 8 向：

- 東：`e`
- 東南：`se`
- 南：`s`
- 西南：`sw`
- 西：`w`
- 西北：`nw`
- 北：`n`
- 東北：`ne`

執行時動畫規則：

- 花子移動時使用 `walk_<方向>`；停止移動時保持最後朝向，並使用 `idle_<方向>`。
- 普通奶牛、厚皮大奶牛、吐奶遠端牛移動時使用 `walk_<方向>`。
- 瘋跑小牛移動時使用 `run_<方向>`。
- 橘貓、黑貓和奶滴按當前飛行方向使用 `fly_<方向>`。
- 奶牛貓按當前飛行方向使用 `spin_<方向>`。

不能只載入 8 向圖集卻固定播放單一方向動畫。正常戰鬥畫面裡，花子、貓、奶滴和牛的朝向不能和運動方向明顯相反或錯亂。

## HUD 佈局

HUD 使用 CanvasLayer 或等價方式固定在螢幕上，鏡頭移動時比例和位置不隨地圖漂移。

左上 HUD 組包含頭像、血條、經驗條和已解鎖貓圖示：

- 頭像位於左上區域。
- 血條位於頭像右側。
- 經驗條位於血條正下方。
- 血條和經驗條的槽體左邊緣、右邊緣、內容內邊距必須視覺對齊。
- 血條填充和經驗條填充必須位於各自槽體內部，不能偏出邊框、懸空、錯位或出現孤立色塊。
- 已解鎖貓圖示位於經驗條下方或左下方，不能遮擋或打斷血條、經驗條的對齊關係。

血條和經驗條的對齊按 1920x1080 基準視口判定。這裡不要求整個 HUD 逐畫素復刻示意圖，但血條和經驗條之間的幾何關係必須可測量：

- 血條槽體矩形：血條可見外框或底槽的外接矩形。
- 經驗條槽體矩形：經驗條可見外框或底槽的外接矩形。
- 血條內容區矩形：血條槽體內部實際允許血量填充出現的區域。
- 經驗條內容區矩形：經驗條槽體內部實際允許經驗填充出現的區域。
- 血條填充矩形：當前血量填充的可見區域。
- 經驗條填充矩形：當前經驗填充的可見區域。

具體對齊要求：

- 血條槽體矩形左邊緣 x 座標與經驗條槽體矩形左邊緣 x 座標，差值不超過 2 px。
- 血條槽體矩形右邊緣 x 座標與經驗條槽體矩形右邊緣 x 座標，差值不超過 2 px。
- 血條內容區矩形左邊緣 x 座標與經驗條內容區矩形左邊緣 x 座標，差值不超過 2 px。
- 血條內容區矩形右邊緣 x 座標與經驗條內容區矩形右邊緣 x 座標，差值不超過 2 px。
- 血條填充矩形必須完整落在血條內容區矩形內。
- 經驗條填充矩形必須完整落在經驗條內容區矩形內。
- 血條填充矩形左邊緣應貼合血條內容區矩形左邊緣，差值不超過 2 px。
- 經驗條填充矩形左邊緣應貼合經驗條內容區矩形左邊緣，差值不超過 2 px。
- 經驗條必須位於血條正下方，不能橫向漂移到頭像下方、槽體外側或獨立成為一塊色塊。
- 如果 HUD 執行時存在整體縮放，上述容差按縮放比例同步放大；未縮放或縮小顯示時，最低容差仍按 2 px 計算。

頂部居中區域顯示波次和新貓提示。右上區域顯示擊殺數和計時。`spec/v0.1-畫面基準-戰鬥HUD示意.png` 是 v0.1 HUD 的視覺基準，用於約束資訊位置、比例、層級和對齊關係。

## 升級彈窗

`spec/v0.1-畫面基準-升級彈窗示意.png` 是 v0.1 升級彈窗的視覺目標，不只是普通參考圖。最終實現不能直接切取或貼用示意圖，但必須按示意圖重繪或生成執行時 UI 資產，並保留它的核心結構、比例和視覺重心。

升級彈窗視覺繫結項：

- 升級三選一彈窗必須居中出現，彈出時壓暗戰場，但戰鬥背景仍然可見。
- 三個升級選項必須是三張並排的豎向大卡片，不得改成長條按鈕列表、普通選單列表或預設系統面板。
- 三張卡片的整體尺寸、間距、視覺重心和佔屏比例應接近 `spec/v0.1-畫面基準-升級彈窗示意.png`。
- 每張卡片必須保留明顯的外框、內框、上半部主內容區、下半部說明區和底部圓形徽章或圖示位。
- 卡片可以根據實際升級內容加入名稱、效果、當前層數和倍率文案，但文案排布不能破壞豎向卡片結構。
- 選中、懸停或可點選反饋可以用描邊、亮邊、發光、顏色變化或輕微縮放表達，但不能把卡片改成其他佈局。
- 允許重新繪製紋理、邊框、圖示和文字樣式；不允許直接切取示意圖作為最終 UI 資源。
- 升級卡外框、內框、底紋、底部徽章和主要圖示必須來自 `assets/sprites/ui/runtime/` 的執行時 UI 資產，或來自這些資產建出的 `.tres`。
- 如果實現仍主要依賴 `draw_rect`、`draw_line`、`draw_circle`、預設 `Button`、預設 `Panel` 或單色 `StyleBoxFlat` 來模擬卡片外觀，即使結構位置接近，也不算達到 v0.1 升級彈窗視覺目標。
- 升級卡必須至少對照 `assets/sprites/ui/reference_crops/upgrade_card_normal_ref.png`、`upgrade_card_gold_ref.png` 和對應升級圖示 crop 生成執行時資產，並保留參考 crop、執行截圖 crop 和並排對照證據。

## 結算與暫停面板

勝利和失敗結算面板居中彈出，展示本局結果、存活時間、擊敗敵人數、放出貓總數、最常用貓或最高傷害貓、升級次數。按鈕和統計文字不能互相遮擋。

暫停面板應明確表示當前暫停狀態，並提供可恢復操作。暫停畫面不能遮擋到無法辨認當前戰場和 HUD 狀態。

## 貓的視覺表現

貓作為一次性子彈發射出去。貓的差異必須透過整貓造型、飛行動畫、彈道、殘影、命中粒子和短暫特效表達。正常畫面不能用常駐命中半徑圈、爆炸預告圈或範圍輔助線替代貓的正式表現。

| 貓 | 正式視覺識別方式 | 不允許的替代方式 |
| --- | --- | --- |
| 橘貓 | 橘色整貓撲擊、直線飛行、短直線殘影、命中小火花 | 常駐命中半徑圈、目標鎖定框 |
| 黑貓 | 黑色整貓撲擊、落點短暫爆炸、煙塵或橙色衝擊波 | 常駐爆炸半徑預告圈、從發射到命中一直顯示的大範圍圓 |
| 奶牛貓 | 奶牛花紋貓、弧線或迴旋軌跡、掃場殘影、短暫命中波紋 | 常駐大範圍圓環、幾何掃場半徑線 |

## 牛的視覺表現

四種牛必須靠正式美術和行為差異被玩家識別。正常畫面不能用頭頂常駐文字、型別徽標、碰撞圈、AI 範圍圈或矩形狀態框來替代敵人造型。

| 敵人 | 正式視覺識別方式 | 不允許的替代方式 |
| --- | --- | --- |
| 普通奶牛 | 標準體型、普通移動動畫、黑白花紋、數量壓力 | 頭頂常駐“普”標籤、腳下碰撞半徑圈 |
| 瘋跑小牛 | 更小體型、更快跑動動畫、明顯前傾、短暫速度殘影 | 頭頂常駐“快”標籤、常駐速度線或檢測線 |
| 厚皮大奶牛 | 更大體型、更厚輪廓、更慢步伐、更沉的受擊反饋 | 頭頂常駐“厚”標籤、紅色矩形框、護甲檢測框 |
| 吐奶遠端牛 | 不同角或嘴部造型、吐奶動作、奶滴彈體、保持距離行為 | 頭頂常駐“遠”標籤、藍色 AI 範圍圈 |

## VFX 與反饋

UI 控制元件、命中、爆炸、經驗、死亡、花子受擊等反饋使用按執行尺寸準備的定製資產或粒子效果。不能直接切原始參考大圖湊成最終效果，也不能只用純色框或預設控制元件代替。

必須能看出：

- 敵人被打到時有閃白、閃爍、粒子或其他可見受擊反饋。
- 貓命中有反饋。
- 黑貓爆炸有範圍特效。
- 奶牛貓掃場能看出命中過程。
- 花子受擊時有可見反饋，並能從 HUD 血量變化看出扣血。
- 戰鬥中可以有輕微震屏、視覺抖動或短暫停頓，但不能影響玩家讀 UI 和走位。

## 除錯輔助層限制

正常遊玩入口必須呈現玩家視角的正式畫面，不顯示除錯輔助層。正式視覺驗收截圖中不得出現：

- 碰撞半徑圈
- 攻擊半徑圈
- 啟用範圍圈
- 刷怪區矩形
- 地圖邊界矩形
- 敵人型別文字標籤
- AI 狀態標籤
- 物件池標記
- 座標標記
- 開發者輔助線

需要這些資訊時，必須透過顯式除錯入口單獨截圖，並在檔名或報告裡標明除錯輔助層已開啟。

## 視覺證據

UI、佈局、動態特效和結算頁必須有真實執行截圖或幀序列證據，不能只靠日誌、控制元件座標或 headless 結果判定透過。

每輪正式視覺驗收至少保留：

- 正常戰鬥 HUD 截圖。
- 升級彈窗截圖。
- 勝利或失敗結算截圖。
- 能看到戰鬥動態、方向動畫、命中或受擊反饋的連續幀或短錄屏。
- 必要時保留參考圖、執行截圖 crop 和並排對照證據。
