# 花子的奶牛关

《花子的奶牛关》是一款 2D 俯视角幸存者类小游戏。你控制花子在户外大地图里走位，花子会不断放出猫猫攻击从四面八方冲来的奶牛。你要一边躲开敌人，一边选择升级，让猫群越打越强，撑过最后一波就能获胜。

## 游戏内容

- 固定户外大地图，镜头跟随花子移动。
- 花子自动放猫攻击敌人，玩家不用手动瞄准。
- 橘猫、黑猫、奶牛猫三种猫有不同攻击方式。
- 普通奶牛、疯跑小牛、厚皮大奶牛、吐奶远程牛会按波次出现。
- 战斗中会出现三选一升级，可以强化伤害、发射频率、移动速度或攻击范围。
- 花子血量归零会失败，撑过最后一波会胜利。

## 操作方式

- 移动：WASD / 方向键
- 选择升级：鼠标点击
- 暂停：Esc / P

## 技术栈

本游戏使用 Godot 4.x 和 GDScript 开发，目标是做成一个轻量、完整、能直接游玩的一局制 2D 小游戏。
